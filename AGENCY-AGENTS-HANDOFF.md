# Agency Agents handoff

The full agency-agents repository is included in this package under:

agency-agents/

These Markdown agent personas were originally installed for Claude Code. Claude Code can use them from its agent configuration, while ChatGPT/Codex can use the same content as project or repository instructions.

The VMS Autopilot interface and product requirements are separate from the agency-agents catalog. Use the catalog as the specialist-agent reference while implementing the product.
