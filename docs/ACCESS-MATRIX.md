# VMS Autopilot Access Matrix

## Admin

Admin can create client workspaces, connect integrations, manage credentials, grant or revoke every permission, approve sensitive actions, execute AI repairs, manage domains and ads, and view audit logs and billing.

## Client

Client sees only their own workspace. By default the client can view and run SEO/GEO audits and download reports, but cannot apply fixes. Paid Ads and Domains are available only when Admin grants permission. Client AI is read-only: it can explain reports and status but cannot execute commands or make modifications.

## Permission levels

- View
- Create
- Edit
- Approve
- Publish/Execute
- Delete
- Billing
- Manage integration
- Grant permission

Only Admin can grant, revoke, or change permissions.

## Sensitive actions

Website deployment, DNS changes, ad budget changes, campaign launch, publishing, account connections, deletion, billing, and AI execution must be logged and may require Admin approval.
